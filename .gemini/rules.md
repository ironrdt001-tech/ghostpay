# Antigravity Rules

## PROTECTED UI - DO NOT MODIFY
The files ghostpay-modal.css, ghostpay-modal.lock.css and GhostPayModalKit.tsx define the modal design.
- Do NOT edit them unless the user explicitly asks you to change the modal design.
- Do NOT restyle modals with inline styles, new classes or Tailwind utilities. Use GPModal, GPAmountField, GPChips and GPButton.
- Do NOT add global input/button/chip selectors that could affect .gp-panel.
- If a task seems to need a change in these files, STOP and ask first.
